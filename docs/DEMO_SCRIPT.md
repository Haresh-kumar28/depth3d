# 5-minute judging demo

1. Create a project named `Campus Terrain Demo`.
2. Upload a JPG/PNG for the relative workflow, or a georeferenced GeoTIFF for the metric workflow.
3. Run reconstruction and show progress through depth -> DSM -> mesh.
4. Open **3D Terrain**, switch RGB -> Relief -> Wireframe, increase vertical relief, and use Iso/Top/Front.
5. Click a terrain point and show elevation + slope.
6. For GeoTIFF, upload a DEM or enter three GCPs and show scale/offset and metric units.
7. Upload a reference DSM/DEM and show RMSE, MAE, R², Pearson correlation and error map.
8. Download metric DSM, GLB and reproducibility report.
9. Explain: monocular depth is relative; DepthWizard adds geospatial calibration and objective reference validation.
