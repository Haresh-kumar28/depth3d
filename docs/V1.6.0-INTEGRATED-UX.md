# DepthWizard v1.6.0 — Integrated Scientific Workstation

This release keeps the v1.5 accuracy and persistence foundation and upgrades the application shell into a connected geospatial workflow.

## Integrated workflow
Prepare → Reconstruct → Calibrate → Validate → Explore → Inspect → Export.

## UX and state improvements
- Persistent collapsible navigation and command palette.
- Project switcher with New, Rename, Reset and Delete actions.
- Project workspace includes the complete reconstruction/calibration/validation/3D flow.
- Reconstruction completion automatically opens 3D Terrain.
- Current-project metadata is cleared and refetched on project switches and uploads to prevent stale spatial information.
- History remains persistent; reconstruction, calibration and validation records can be removed explicitly after confirmation.
- Current calibration/validation identifiers remain backend-driven.
- Contextual inspector shows surface metrics or live point elevation.
- 3D Terrain includes layers, grid toggle, vertical exaggeration, camera presets, orbit/fly modes, fullscreen and inspection history.
- Larger typography and stronger metric hierarchy improve readability.
- Workflow health and next-step guidance reduce manual page hopping.
- Error Analysis exposes validation metrics, P95 error, coverage and scientific interpretation.

## Scientific integrity
No benchmark numbers are changed by the interface. Reconstruction history records model/settings, while calibration and validation remain provenance-aware.
