# Aerial-Depth checkpoint directory

This directory is intentionally empty in the release.

A real fine-tuned Depth Anything V2 checkpoint may be deployed here only after:
1. training on paired aerial RGB + DSM data,
2. geographic train/validation/test split,
3. frozen held-out test evaluation,
4. baseline comparison,
5. checkpoint SHA-256 and provenance are recorded.

DepthWizard will report Aerial-Depth as unavailable until a complete checkpoint is present.
