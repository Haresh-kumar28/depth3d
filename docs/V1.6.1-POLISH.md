# DepthWizard v1.6.1 — Scientific Workstation Polish

## UX fixes
- The project context inspector is rendered only inside the 3D Terrain workspace; standard workspaces use the full content width.
- Success toasts auto-dismiss after a short interval; error toasts remain available for diagnosis.
- Reconstruction progress is now live because the blocking depth pipeline runs off the FastAPI event loop.
- Tiled depth inference reports per-tile progress to the status API.

## 3D workspace
- Terrain is fit more prominently to the viewport.
- The ground grid is derived from the actual loaded terrain bounding box rather than a fixed world origin.
- Grid, floor reference and axes stay spatially aligned with the terrain base.
- Orbit camera fit is tightened for a more CAD/engineering-workstation presentation.
- Existing RGB/elevation/relief/slope/wireframe and inspection controls are preserved.

## Scientific integrity
- No benchmark values are fabricated.
- Progress is operational status, not an accuracy claim.
- Calibration/validation history remains persistent.
