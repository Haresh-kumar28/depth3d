# DepthWizard v1.4.0 — Accuracy Upgrade

## What changed
- Aerial imagery now uses overlapping tiled Depth Anything V2 inference by default.
- 768 px tiles with 25% overlap are blended with a center-weighted window to reduce boundary seams.
- Processing reports record inference mode, tile size and overlap for reproducibility.
- The UI labels reconstruction as high-accuracy tiled inference.

## Why
Whole-scene monocular inference can lose local structure when a large orthophoto is resized into the model input. Tiling preserves more local spatial detail. This is an engineering improvement that must be validated empirically; it is not a guarantee of a particular RMSE.

## Next accuracy stage
For SIH-quality accuracy claims, compare this pipeline against an aerial-domain fine-tuned model and use independent validation references not used during calibration.
