# DepthWizard v1.7.0 — Final SIH Workstation Polish

## Purpose
This release consolidates the final SIH-grade workflow without adding decorative or unverified capabilities.

## Functional hardening
- Backend status exposes the active/latest job state and timing.
- Reconstruction progress is live and tied to actual tiled inference callbacks.
- Meaningful processing stages are persisted so refreshes do not silently lose the current progress snapshot.
- Reconstruction settings, calibration split and seed are persisted in project state.
- Success notifications auto-dismiss; errors remain dismissible.

## 3D workspace
- Right Inspector is exclusive to the 3D Terrain workspace.
- Terrain viewport is a flex-filled workspace rather than a fixed-height card.
- Grid/floor/axes are derived from the loaded terrain bounding box and stay in the same transformed scene space.
- Camera framing is calculated from the actual terrain bounds.
- Contours are generated from the loaded terrain mesh only when enabled; no synthetic reference data is implied.
- Existing RGB/elevation/relief/slope/wireframe/shadows/fly/orbit/inspection behavior is preserved.

## Scientific integrity
- No accuracy values are fabricated.
- Model benchmark results remain measured-only.
- Aerial-Depth remains unavailable until a genuine local checkpoint exists.
- DEM/DSM semantics and independent validation remain explicit.
